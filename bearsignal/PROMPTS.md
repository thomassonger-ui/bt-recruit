# BearSignal Prompts

## Post Generation
Create a LinkedIn post for a real estate agent focused on [topic]. Tone: authoritative, system-driven, no fluff.

## Carousel
Create a 5-slide carousel explaining [topic]. Each slide concise and bold.

## Email
Write a recruiting email targeting agents producing 4–9 deals/year focusing on systems and no fees.

## Formatting Rule
Always adapt output to:
- LinkedIn (long-form, story-led)
- Facebook (engaging, community)
- X (short-form, sharp)
- Email (direct, one CTA)
