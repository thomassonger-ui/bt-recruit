# BearSignal
BearSignal is the automated marketing engine of Bear Team.
It creates, schedules, and distributes content across LinkedIn, Facebook, X (Twitter), and email—driving consistent visibility, inbound leads, and agent brand growth.

## Role in Ecosystem
- BearTeamOS → Operate
- Scout → Think
- BearSignal → Market (Create + Distribute)

## Core Functions
- Content generation (AI-powered via Scout)
- Multi-channel distribution
- Campaign automation
- Social + email alignment
- Lead generation support
