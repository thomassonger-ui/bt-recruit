# BearSignal Roadmap

## Phase 1 — Manual + Assisted Posting
- Define content pillars per channel
- Build template library
- Connect Scout for AI content generation
- Prompt-driven content creation workflow

## Phase 2 — Scheduling System
- Vercel cron job for scheduled posting
- Queue-based publishing system
- Supabase lead capture from social/email
- SendGrid email campaign integration

## Phase 3 — Auto-Posting Integrations
- LinkedIn API
- Facebook Graph API
- X (Twitter) API
- Trigger-based campaigns (new listing, new agent, re-engagement)

## Phase 4 — Performance Tracking + AI Optimization
- Analytics dashboard (engagement, leads, conversions)
- A/B testing for post formats and email subject lines
- Scout learns from performance data
- Agent-level personal brand automation
