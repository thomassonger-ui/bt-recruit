# BearSignal Architecture

## Flow
```
Scout (AI)
↓
Content Generation
↓
Template Formatting
↓
Queue / Scheduler
↓
Channel Distribution
↓
Engagement → Leads
↓
BearTeamOS Pipeline
```

## Key Components
- Scout → content intelligence
- Templates → structure output
- Scheduler → timing control
- API integrations → posting
- CRM → lead capture

## Integration Points
- Supabase (leads + tracking)
- SendGrid (email)
- Vercel cron (automation)
